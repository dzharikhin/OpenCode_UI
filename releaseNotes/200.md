## 2.0.0

### Breaking Changes

- **Minimum IDE version**: Requires IntelliJ IDEA 2026.2 or newer (build 262+). Older IDE versions are no longer supported and will not receive updates.
- **Reworked Terminal API**: OpenCode now runs in a real editor tab backed by a detached terminal session from the 2026.2 Terminal plugin. As a consequence, clickable `@path#Lx-y` file links inside the terminal output are no longer available (the reworked terminal exposes no plugin API for custom hyperlink filters).

### Requirements

- **Web mode**: JCEF was extracted from the platform into the bundled *Web Browser (JCEF)* plugin in 2026.2. Enable that plugin to use the Web interface.

### Fixes

- The multi-file diff viewer again opens at the requested file index (`DiffRequestChain.setIndex` became a no-op in 2026.2; the initial index is now passed to the chain constructor).

### Internal

- Replaced deprecated VFS listener registration with a `BulkFileListener` on `VirtualFileManager.VFS_CHANGES`.
- Replaced deprecated `java.net.URL(String)` constructor with `URI(...).toURL()`.
